### 説明

ここは『ゆるっとはじめるGodot Engineゲームプログラミング』のサポートサイトです。

このページ右上の緑の「Code」ボタンをクリックしたのちに「Download ZIP」をクリックしてZIPファイルをダウンロードして展開してください。

素材集フォルダの中に各ゲームの素材がまとめてあるフォルダが入っています。

その他のフォルダには、各ゲームのサンプルプロジェクトが入っています。

サンプルプロジェクトを開くには、各ゲームのproject.godotファイルをGodot Engineからインポートで開いてください。

# 誤植・修正情報
誤植がありましたら、書籍巻末にあるメールアドレスやissueにてご連絡頂ければ幸いです。

**2026/02/17** — 2.9.3 体力の増減と表示のプログラム

- **誤）** health という変数を宣言してその中に100を代入、その次に health_bar という変数を宣言してその中にHealthノードを代入してね。
- **正）** hp という変数を宣言してその中に100を代入、その次に health という変数を宣言してその中にHealthノードを代入してね。
